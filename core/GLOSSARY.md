# Glossary

Project vocabulary. Add terms here to ensure consistent naming across
agents and sessions.

| Term | Definition |
|---|---|
| Harness | Operating contract between humans and agents |
| Intake | The gate where work is classified before implementation |
| Lane | Risk category: tiny, normal, or high-risk |
| Story | A scoped work packet with validation expectations |
| Decision record | Durable record of why architecture changed |
| Trace | Record of what happened during a task |
| Product delta | Changes to app code, tests, or product docs |
| Harness delta | Changes to templates, backlog, or process docs |
| Friction | Difficulty or confusion encountered during a task |
| Proof | Evidence that a behavior works (test, screenshot, log) |
| Test matrix | Mapping of behaviors to their proof status |

Add project-specific terms below after `/init`.
