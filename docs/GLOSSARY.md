# Glossary

## Harness
Quy trình cốt lõi và hệ điều hành cấp repository hướng dẫn người dùng và AI agent chuyển giao ý tưởng thành code an toàn.

## Durable Layer
Cơ sở dữ liệu SQLite (`harness.db`) và CLI `rig` lưu trữ và truy vấn trạng thái hoạt động thực thi.

## Risk Lanes
Ba mức phân loại rủi ro: `tiny`, `normal`, `high-risk`.

## Trace
Bản ghi có cấu trúc ghi lại những gì agent đã thực hiện sau mỗi task loop.
