# Create PPTX Slides

Chuyển đổi bài học Markdown thành slide PowerPoint chuyên nghiệp.

## Quy trình

### 1. Phân tích cấu trúc bài học
- Tiêu đề $\rightarrow$ Title slide
- Mục tiêu bài học $\rightarrow$ Objectives slide
- Các đề mục $\rightarrow$ Divider / Agenda slide
- Nội dung chi tiết $\rightarrow$ Content slides (3-4 ý chính / slide, kèm speaker note 200-300 từ)
- Tổng kết $\rightarrow$ Summary slide
- Bài tập $\rightarrow$ Exercise slide

### 2. Sinh hình ảnh & Âm thanh
- Tạo hình ảnh minh họa cho các slide trọng tâm.
- Tạo file audio thuyết minh TTS cho từng slide (giọng nam/nữ).

### 3. Xuất file PPTX
- Tạo file `.pptx` hoàn chỉnh nhúng sẵn speaker notes và audio.
